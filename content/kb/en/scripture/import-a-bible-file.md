# Import a Bible file

Selah reads OSIS, USFM, and Zefania Bible files stored on your computer. Leave **Format** on **Detect format** if you are unsure of the file type.

## Steps

1. Open **Library** and select **Bibles**.
2. Under **Bible file path**, enter the path to your Bible file.
3. Type a **Short code** like `ASV` and a **Translation name**.
4. Leave **Format** on **Detect format**, or pick **OSIS**, **USFM**, or **Zefania**.
5. Select **Import Bible**.

> [!WARNING]
> Only import Bible translations that you have permission or a public-domain licence to use.
