# Reuse last week's service

Most weeks follow the same order. Start from last week and change only what is new.

## Steps

1. Select **Services**.
2. In **Upcoming services**, choose last week's service.
3. Select **Inherit from last week**.
4. Change the **Service name** if you need to.
5. Swap the songs and readings that are new this week.
6. Select **Save service**.

The new service keeps the order, the songs, the looks, and the team.

## If it doesn't work

- If nothing is copied, choose a service in **Upcoming services** first.
