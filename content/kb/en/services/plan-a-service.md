# Plan a service

A service is the list of things you show, in order. It can hold songs, Bible readings, media, slides, countdowns, and notes.

## What a plan holds

- Each song, reading, or video is one item. Sections like "The Word" help split up a long list.
- Each item has a length. Selah adds them up so you can see when the service ends.
- Each item can have an owner. The team roster lists who serves.
- Each item can use a look, so the screens change by themselves.

## A good order of work

1. Choose a service type, like Sunday 9:00 AM.
2. Start from last week's service, or make a new one.
3. Add and order the items.
4. Run the Ready for Sunday check.
5. Practise once, then go live.
