# Print the service order and chord charts

You can export a clean service sheet and song chord charts from the planner. If a song has a key override for the week, Selah transposes the printed chords to match.

## Steps

1. Open **Services** in the top bar and pick your service.
2. Select any song item and set **Key override** if the band is playing in a new key.
3. Select **Print service order** to export the schedule table with times, looks, and owners.
4. Select **Print chord charts** to export one chord sheet per song with chords above the words.
