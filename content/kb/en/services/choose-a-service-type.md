# Choose a service type

A service type is a starting point, like Sunday 9:00 AM. It sets the start time, the length, and the look for each new service.

## Steps

1. Select **Services**.
2. In **Service types**, choose a type.
3. Select **New service** or **Inherit from last week**.

The new service starts with the time and look of that type.

> [!TIP]
> Each type keeps its own weeks. Inherit from last week copies the last service of the same type.
