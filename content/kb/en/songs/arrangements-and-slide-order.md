# Set song arrangements and order

An arrangement sets the order of verses, choruses, and bridges. You can reuse the same chorus many times without typing it twice.

## Steps

1. Open a song in **Song editor** and go to the **Arrange** step.
2. Under **Arrange** on the right, pick an existing list or select **New arrangement**.
3. Type a clear name under **Arrangement name**, such as Sunday order.
4. Select any section card to add it to **Order in service**.
5. Select **Save song** when the slide order looks right.

> [!NOTE]
> Use **Clear order** if you want to start the section list over.
