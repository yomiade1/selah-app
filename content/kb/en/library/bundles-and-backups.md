# Back up and share your library

Save a full backup before making big changes, or pack songs and media into a `.selah` bundle for another computer.

## Steps

1. Open **Library** and scroll to **Bundles and backups**.
2. To share songs and media, enter a file path and select **Export bundle** or **Import bundle**.
3. To back up the whole library, enter a ZIP path and select **Create backup**.
4. To bring a backup back, select that ZIP file and choose **Restore backup**.

> [!WARNING]
> Restoring a backup replaces the library in this folder. Create a fresh backup first if you aren't sure.
