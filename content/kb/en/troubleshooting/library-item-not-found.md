# Library item not found

Selah couldn't find that item in your library. Someone or another window may have removed it.

## Try these in order

1. Use Undo if you removed the item by mistake.
2. Search your library for the item's name. It may have a new title.
3. Check whether a media file on disk moved or lost its drive.
4. If the problem keeps happening, select **Help**, then **Report a problem**.
