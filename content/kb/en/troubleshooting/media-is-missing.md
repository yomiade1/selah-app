# A file is missing or changed

Selah keeps its own copy of each picture, video and sound file. This message means that copy is gone or damaged.

## Try these in order

1. Select **Library**, then **Media**.
2. Add the file again from your computer.
3. Open the service and pick the new file for that item.
4. Select **Check the service** again.

## Still not working?

- Restore a backup of your library in **Library**.
