# Selah couldn't save a library item

Selah checks each song, template, and media item before it saves. Your earlier copy stays safe if a save fails.

## Try these in order

1. Make sure the item has a short non-empty title.
2. Check that section names, chords, and slides are valid.
3. Check that your disk still has free space.
4. If the problem keeps happening, select **Help**, then **Report a problem**.
