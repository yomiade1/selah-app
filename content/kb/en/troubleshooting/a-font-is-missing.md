# A font is missing

A template in this service asks for a font Selah doesn't have. Selah shows a plain font instead, so the slides may look different.

## Try these in order

1. Select **Templates** and open the template.
2. Pick a font that comes with Selah, like Inter, Manrope or Noto Serif.
3. Save the template.
4. Select **Check the service** again.
