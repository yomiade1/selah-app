# Selah started in safe mode

Selah starts in safe mode when it closed 3 times in a minute. It also starts this way if you hold [[Shift]] as it opens.

In safe mode, Selah turns off the parts that are most likely to cause trouble. Your songs and services are safe.

## Try these in order

1. Keep going if you are in a service. You can still show slides and clear the screens.
2. When the service ends, close Selah. Then open it again. It starts the normal way.
3. If it starts in safe mode again, select **Help**, then **Report a problem**. Send the file to our support team.

## What is off in safe mode

- Video cards and other outputs that need extra parts.
- Add-ons that other people made.

> [!NOTE]
> The yellow bar at the top stays while safe mode is on. Select **Learn why** to read this help.
