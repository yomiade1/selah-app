# Report a problem

If something goes wrong, you can send us a support file. It helps us find the problem fast. It has no passwords and no names in it.

## Steps

1. Select **Help**, then **Report a problem**.
2. Selah saves a support file. It shows you where the file is.
3. Selah opens a form on our website. The version of Selah is filled in for you.
4. Say what you were doing and what went wrong. Add the support file.
5. Send the form.

> [!TIP]
> Write down the time the problem started. It helps us find it in the file.
