# Check how well Selah runs on this computer

Diagnostics shows details about this computer, like its graphics card and screen size. It can also run a short test of how fast Selah runs here. The test saves a report you can send to us.

## Steps

1. Clear the screens. The test can't run while something is on them.
2. Select **Help**, then **Diagnostics**.
3. Select **Run benchmark**. It plays a test video and takes about a minute.
4. When it's done, you see the results. Selah saves a report.
5. Select **Show the report** to find the file. Add it to your problem report.

> [!TIP]
> Run the test when nothing else is busy on the computer. The results are more useful.
