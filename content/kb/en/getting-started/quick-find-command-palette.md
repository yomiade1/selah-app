# Quick find and commands

Quick find lets you search everything in Selah from one bar. You can jump straight to a song, verse, command, or help guide.

## Steps

1. Select **Quick find** in the toolbar, or press [[Ctrl]]+[[K]].
2. Type a song title, Bible words, media name, command, or help question.
3. Select the result you want to open it right away.
4. Press [[Esc]] or select **Close** if you want to return without changing screens.

> [!TIP]
> Quick find sits below the toolbar so **Clear everything** stays open and visible.
