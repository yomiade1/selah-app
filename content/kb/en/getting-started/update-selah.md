# Update Selah

Selah never looks for updates on its own. You turn update checks on, and Selah looks only when you ask. It never installs an update while something is on the screens.

## Steps

1. Select **Settings**.
2. Under **Updates**, turn on **Let Selah check for updates when I ask**.
3. In **Update address**, paste the address your team gave you. Select **Save address**.
4. Select **Check for updates**.
5. If a new version is ready, select **Install update**.
6. Selah checks the download. Then it closes and opens again with the new version.

> [!NOTE]
> If something is on the screens, Selah asks first. Select **Clear and update** to clear the screens and update. Select **Keep showing** to wait.

## If it doesn't work

- If Selah says update checks are off, turn on **Let Selah check for updates when I ask**. Then try again.
- If Selah can't read the update address, check that it starts with https:// and that you're online.
- If the update didn't download correctly, Selah didn't install it. Nothing changed. Try again later.
