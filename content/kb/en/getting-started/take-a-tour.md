# Take a tour

A tour points at each part of the screen and says what it does.

## Steps

1. Select **Help**, then **Start tour**.
2. Pick a tour: **Run slides in 5 minutes** or **Producer mode overview**.
3. Read each step. Select **Next** to go on, or **Skip tour** to stop.

> [!NOTE]
> Tours don't start while the screens in the room show something. Clear the screens or select **Start practice** first.
