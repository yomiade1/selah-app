# Set up Selah the first time

The first time you open Selah, it asks a few questions. It takes about 2 minutes.

## Steps

1. Read **Welcome to Selah**, then select **Next**.
2. Check the screens Selah found. Select **Next**.
3. Pick the Bible Selah opens first. Select **Next**.
4. Type your **CCLI licence number** if you have one. Select **Next**.
5. Select **Add the sample service** to get three old hymns to practise with.
6. Select **Finish**.

You can change all of this later. To skip the questions, select **Skip setup**.
