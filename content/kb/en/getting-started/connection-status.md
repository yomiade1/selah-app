# Check the connection status

The pill next to the app name in the toolbar shows how Selah's parts are talking.

## What each label means

- **Connected**: The window, core, and screen engine are ready.
- **Connecting…**: Selah is still starting up. Wait a few seconds.
- **Screens not connected**: Core is running, but the screen engine isn't answering yet.
