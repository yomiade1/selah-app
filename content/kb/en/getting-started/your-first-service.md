# Run your first service

This is the whole path, from a new copy of Selah to your first Sunday.

## Steps

1. Finish the setup steps that Selah shows the first time it opens.
2. Select **Services**, then **New service**.
3. Select **Add song** and **Add scripture** to build the order.
4. Select **Save service**.
5. Run the **Ready for Sunday?** check and fix what it finds.
6. Select **Live**, then **Start practice**, and go through the service once.
7. Select **Stop practice**.
8. On Sunday, load the service and press Space for each slide.

> [!TIP]
> If something goes wrong on screen, press F12. Every screen clears at once.
