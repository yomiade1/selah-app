# Organise and delete media

Find files fast in a busy Media bin using kind filters and search, or delete items you don't need.

## Steps

1. Open **Library** and select **Media**.
2. Choose **All**, **Images**, **Video**, or **Audio** to filter the grid.
3. Type words in **Search library** and select **Search** to match names or tags.
4. Select an item you want to remove.
5. Select **Delete media**.

> [!TIP]
> If you remove the wrong item, select **Undo** to bring it back.
