# Add pictures, video, and audio

The Media bin stores pictures, videos, and audio files inside Selah's own folder so nothing gets lost if you move a USB drive.

## Steps

1. Open **Library**, then select **Media**.
2. Select **Import media** and choose an image, video, or audio file on your computer.
3. Wait a moment for Selah to save the file and build a thumbnail preview.
4. Use **Search** and the kind filter to find your file by name, image, video, or audio.
5. Select an item and choose **Delete media** if you no longer need it.

> [!NOTE]
> Selah checks every imported file with a hash so corrupted or moved files don't break your library.
