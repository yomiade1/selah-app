# Make a look

A look picks which layers each screen shows. For example, a lobby screen can show the background but not the words.

## Steps

1. In **Live**, select the **Set up tiles** tab.
2. In **What to make**, choose **Look**.
3. Type a **Name**, like "Lobby".
4. Under **What each screen shows**, find the screen.
5. Untick the layers that screen should not show.
6. Type a **Key** if you want one, like 2.
7. Select **Save**.

## Use it

- Select the look's tile in **Looks, timers and macros**.
- Or press Shift and its key, like Shift+2.

The tile that is on now is filled in.
