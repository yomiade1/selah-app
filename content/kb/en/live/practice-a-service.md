# Practise a service

In practice mode, you can run a service the same way as on Sunday. The screens in the room keep showing what they showed before.

## Steps

1. In **Live**, select **Start practice**.
2. A yellow bar says **Practice mode**. Your changes show in Selah only.
3. Run the service. Try **Next slide**, the number keys and **Hide words**.
4. When you're done, select **Stop practice**. Selah puts everything back the way it was.

> [!NOTE]
> **Clear everything** and F12 still clear the real screens, even in practice mode.

> [!TIP]
> Practice mode is a good time to take a tour. Select **Help**, then **Start tour**.
