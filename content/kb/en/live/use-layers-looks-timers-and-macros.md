# Use layers, looks, timers, and macros

What is on screen is made of layers. A look picks which layers show on each screen.

## Layers

**Layers** lists **Messages**, **Props**, **Slide**, **Media**, and **Video input**. Each row says what it shows now. Select **Clear** to hide one layer.

## Tiles

Select the **Looks, timers and macros** tab.

1. Select a look tile to change what each screen shows. You can also press Shift and the look's number.
2. Select a timer tile to start it. Select it again to pause it.
3. Select a macro tile to run its steps. You can also press its key.

> [!TIP]
> The tile that is on now is filled in.
