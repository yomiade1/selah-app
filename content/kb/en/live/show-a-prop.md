# Show a prop over the slide

A prop puts a few words over the slide. Use one for a speaker's name or a short notice.

## Make a prop

1. In **Live**, select the **Set up tiles** tab.
2. In **What to make**, choose **Prop**.
3. Type a **Name** and the **Words** to show.
4. Set **Hide after (seconds)** if it should go away by itself. Leave 0 to keep it up.
5. Select **Save**.

## Show and hide it

1. In **Looks, timers and macros**, select the prop's tile.
2. Select the tile again to hide the prop.

Only one prop shows at a time. A new prop takes the place of the last one.
