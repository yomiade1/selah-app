# Show a message on the screens

A message shows a short notice over the slide. Use it for things like a parking notice or a call from the nursery.

## Make a message

1. In **Live**, select the **Set up tiles** tab.
2. In **What to make**, choose **Message**.
3. Type a **Name**, then the **Message**.
4. Set **Hide after (seconds)**. Leave 0 to keep it up until you hide it.
5. Tick **Show on stage screens only** if only the people on stage should see it.
6. Select **Save**.

## Show it

1. In **Looks, timers and macros**, select the message's tile.
2. Select the tile again to hide it early.

> [!TIP]
> Put timer in curly brackets in the message. Selah fills in the time left on the timer that is running.
