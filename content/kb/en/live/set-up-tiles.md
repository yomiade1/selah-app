# Set up tiles for the service

Set things up before the service starts. Then each one is a tile you select while you are live.

## Steps

1. Select **Live**, then **Producer**.
2. Select the **Set up tiles** tab.
3. In **What to make**, choose what you want.
4. Type a **Name**.
5. Fill in the rest of the boxes.
6. Select **Save**.

Your new tile shows in the **Looks, timers and macros** tab.

## Change or delete one

1. In **Saved**, choose the one you want.
2. Change it, then select **Save**.
3. Or select **Delete** to remove it and its tile.

Select **New** to start a fresh one.

> [!TIP]
> The **Next** and **Clear all (F12)** buttons stay on screen while you set things up.
