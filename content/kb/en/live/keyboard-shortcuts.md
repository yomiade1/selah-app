# Keyboard shortcuts for running a service

These keys work in **Live** when no text box is selected.

## Move through the service

| Key | What it does |
|---|---|
| Space, Right arrow, or Down arrow | Next slide |
| Left arrow or Up arrow | Previous slide |
| Shift+Right arrow | Next item |
| Shift+Left arrow | Previous item |
| 1 to 9 | Show that verse or section |

## Clear the screens

| Key | What it does |
|---|---|
| F12 | Clear every screen |
| Hold Esc for 1 second | Clear every screen |
| F10 | Clear the words |
| F11 | Clear the background |
| F9 | Show or hide the logo |

## Undo and the booth

| Key | What it does |
|---|---|
| Ctrl+Z | Undo the last change on screen |
| Ctrl+Y | Redo |
| Ctrl+L | Lock or unlock the booth |

## Tiles

- Press a macro's key to run it.
- Press Shift and a look's key to change the look.

On a Mac, use Cmd in place of Ctrl.
