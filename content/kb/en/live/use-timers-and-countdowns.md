# Use timers and countdowns

A timer helps everyone keep to time. The stage display can show it to the speaker.

## Make a timer

1. In **Live**, select the **Set up tiles** tab.
2. In **What to make**, choose **Timer**.
3. Type a **Name**, like "Sermon".
4. In **Kind of timer**, choose **Count down**, **Count up**, or **Count down to a time**.
5. Set the **Minutes**, or the time of day to count down to.
6. In **At zero**, choose what happens when time runs out.
7. Select **Save**.

## What happens at zero

- **Stop at zero** stops the timer.
- **Keep counting past zero** shows how far over you are.
- **Run a macro** runs the macro you choose in **Macro to run**.

## Start and pause it

- Select the timer's tile to start it.
- Select the tile again to pause it.
