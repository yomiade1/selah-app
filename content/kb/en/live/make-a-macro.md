# Make a macro

A macro does a list of steps at once. For example, one tile can change the look and start the sermon timer.

## Steps

1. In **Live**, select the **Set up tiles** tab.
2. In **What to make**, choose **Macro**.
3. Type a **Name** and, if you like, a **Key**.
4. In **Step**, choose what to do.
5. In **Use**, choose the look, timer, or other thing the step needs.
6. Select **Add step**.
7. Add more steps the same way.
8. Select **Save**.

The steps run from the top down. Select **Move up** to change the order, or **Remove** to take a step out.

## Use it

- Select the macro's tile in **Looks, timers and macros**.
- Or press its key when no text box is selected.

> [!NOTE]
> A macro can't run another macro. This keeps a macro from running forever.
