# Run a service in Simple mode

Simple mode shows only what you need. The left picture is **On screen now**. The right picture shows what comes next.

## Steps

1. Press Space, or select **Next slide**, to show the next slide.
2. Press the left arrow, or select **Back**, to go back one slide.
3. Select **Next song** to start the next item in the service.
4. Select any slide under **All slides in this song** to show it now.

The bar at the top shows where you are in the service. Done items have a check mark.

## If something looks wrong

- Press Esc, or select **Hide words**, to hide the words.
- Press F12, or select **Clear everything**, to clear every screen.
- Select **Message the booth** to ask the booth team for help.
