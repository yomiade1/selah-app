# Selah

> Working name. Not yet built. This repository currently holds the plan, the design reference and the build documents.

## How to build it

Selah is built in Claude Code cloud sessions. Set up once with [docs/CLOUD-DEVELOPMENT.md](docs/CLOUD-DEVELOPMENT.md). Then start a session and say **"Complete milestone 1"**.

Each session ends by opening a pull request. You review it, install the test build from it on your PC, and merge it. Then say "Complete milestone 1" again to continue, or the next number once the milestone is done. Sessions resume from PROGRESS.md.

Some steps need you, for example approving installs, hardware, partner accounts or reviewers. They're listed in [BUILD-PLAN.md, Appendix A](BUILD-PLAN.md#appendix-a-human-tasks-owner-you) and tracked in PROGRESS.md.
