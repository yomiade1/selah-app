# Security policy

Selah is in early development and hasn't been released yet. We still want to hear about security problems now.

## Reporting a vulnerability

**Don't open a public issue.** Report it privately instead:

1. Go to the repository's **Security** tab.
2. Select **Report a vulnerability**.
3. Describe the problem, how to reproduce it, and what someone could do with it.

We'll acknowledge your report within 7 days and keep you updated until it's fixed. Please give us a reasonable time to fix the problem before you share details publicly.

## What's in scope

- The Selah desktop app and its processes
- The local network API and the web apps (remote, pastor view, stage display)
- Installers and the update feed
- The build and CI workflows in this repository

## Supported versions

Until v1.0, only the latest build from `main` is supported.

The security and safety requirements, and the threat model, are in [docs/SECURITY.md](docs/SECURITY.md).
